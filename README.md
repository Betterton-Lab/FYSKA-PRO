# FYSKA-PRO

FYSKA-PRO is an extended version of the original FYSKA, with additional capabilities for tracking microtubule protrusions and generating three-point segmented kymographs.

The original FYSKA remains unchanged to preserve code stability and reproducibility of previously published research.

This repository was made public early to provide a software reference for Bojun Zhou's PhD dissertation.

**Development status (November 11, 2026):**

The current version is functional but remains under active development.

A complete README and documentation are coming soon!

**Planned features:**
- A dedicated graphical user interface (GUI).
- A standalone Windows executable (.exe) for public release.
- Integration with Fiji (ImageJ) as a plugin.
